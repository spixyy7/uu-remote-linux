Viewer responsiveness and polish / 控制端响应与细节改进。

- **Lower input latency**: a picture is shown as soon as it is decoded instead of waiting for the next remote frame,
  so a typed letter appears right away; mouse motion within one poll is coalesced, so dragging no longer queues up
  on a relayed connection.
  输入延迟更低：画面解码后立即显示，不再等待下一帧，打字即时显示；同一轮询内的鼠标移动合并发送，经中转连接拖动不再积压。
- **English errors in the English UI**: known server messages (target already controlled, assistance refusals) are
  translated; unknown ones show the error code. 英文界面下显示英文错误信息。
- **Language switch applies at once**: the launcher restarts itself; open sessions stay connected.
  切换语言后启动器自动重启并立即生效，已打开的会话不受影响。
- **Device info** shows real data only (name, status, system, selectable device ID). 设备信息仅显示真实数据。
- No green focus frame on mouse clicks in the launcher. 启动器点击按钮不再出现绿色焦点框。
- Host window shows the account picture when the account has one. 账号有头像时主机窗口显示头像。
- Test fixes: portal build message, parallel `type_ipc` tests. 测试修复。

Install: `uu-remote-linux_0.3.1_<amd64|arm64>.deb` or `uu-remote-linux-v0.3.1-<x86_64|aarch64>-linux.tar.gz` (`./install.sh`).
