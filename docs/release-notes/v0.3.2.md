Phone control on GNOME, drag-and-drop uploads in the viewer, steadier video / GNOME 手机控制、控制端拖放上传、视频更稳定。

**Host / 被控端**
- **Phone drags scroll, a held finger selects, a tap clicks** (GNOME portal, official Android/iOS viewers in touch
  mode): moving the finger scrolls smoothly and the content follows it, also in terminals; holding still for about
  half a second selects like a mouse drag. No extra permission is needed. `UU_TOUCH_INPUT=touch` replays the finger on
  the portal touchscreen instead (asks GNOME once for the touchscreen if the saved consent lacks it);
  `UU_TOUCH_INPUT=0` keeps plain mouse drags.
  手机拖动即滚动（内容跟随手指，终端里同样有效），按住约半秒后拖动为选中，短按为点击；无需额外授权。
  `UU_TOUCH_INPUT=touch` 改为真触控（已保存授权没有触摸屏时会向 GNOME 再申请一次），`=0` 保持鼠标拖动。
- **Typing from the phone on GNOME**: plain letters, digits and symbols are typed as keys on Latin layouts, so a
  terminal no longer pastes the last selected text for every letter, and the clipboard stays untouched. Other text
  still goes through the clipboard. 手机输入法输入英文时直接按键输入，终端里不再粘贴上次选中的文字，也不覆盖剪贴板。
- Diagnostics: the log shows which features the connecting viewer announces (numbers only). 日志记录控制端声明的功能（仅编号）。

**Viewer / 控制端**
- **Drop files or folders on the desktop window** to upload them. On a Windows host they land in the Explorer folder
  or on the desktop under the pointer, found through a short-lived cmd on the same connection (nothing is added to
  the remote PowerShell history; `UU_VIEWER_DROP_PROBE=0` always uses the Desktop). A card shows progress and size
  with **Pause/Resume** and **Cancel**. 把文件或文件夹拖进桌面窗口即上传：Windows 被控端放到光标下的资源管理器文件夹或桌面
  （经同一连接上的临时 cmd 查询，不写入远端 PowerShell 历史）；进度卡片可暂停/继续、取消。
- **Quality, frame rate and true color are remembered** across sessions. 跨会话记住画质、帧率和真彩设置。
- **Steadier video on lossy links**: lost packets are recovered by retransmission instead of waiting for a key frame,
  and the data channel retransmits after 400 ms at the least. `UU_VIEWER_RELAY=tcp` relays over the cloud's TURN
  TCP/TLS entries for links where UDP loses too much.
  丢包线路上更稳定：靠重传补包而不是等待关键帧；数据通道最小重传超时 400 ms；`UU_VIEWER_RELAY=tcp` 走云端 TURN 的 TCP/TLS 中转。
- Each session's log is kept in `$XDG_STATE_HOME/uuremote/viewer-session.log` (no file names, paths or typed text).
  每个会话的日志保存在本机，便于排查断线（不含文件名、路径和输入内容）。
- Hosting this computer from the viewer is opt-in (off by default); SDL event types that sdl2 0.37 does not know no
  longer crash the window. 本机被控默认关闭，需在设置中开启；修复未知 SDL 事件类型导致的崩溃。
