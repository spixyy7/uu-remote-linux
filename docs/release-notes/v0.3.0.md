First release of the spixyy7 fork / spixyy7 分支的首个版本。

- **English / Chinese UI** in every window and message; switch in Settings → General → 语言 / Language (or `UU_LANG`).
  中英文界面，可在 设置 → 常规 → 语言 / Language 切换（或 `UU_LANG`）。
- **Sharper viewer picture**: native-resolution decoding and filtered scaling. 控制端按原始分辨率解码并平滑缩放，文字清晰。
- **Loading screen** instead of a black window. 连接时显示加载动画，不再黑屏。
- **Control center** (`Ctrl+Alt+M` or the tab at the top): quality, frame rate, true color, resolution, window mode, volume,
  lock / mute the remote, system shortcuts, file transfer, watch mode, full screen, disconnect.
  控制中心：画质、帧率、真彩、分辨率、窗口、音量、自动锁屏 / 静音、系统快捷键、文件传输、观看模式、全屏、退出远控。
- **Network status** panel (`Ctrl+Alt+G`, remembered). 网络状态面板（`Ctrl+Alt+G`，会记住）。
- **Device previews** on the launcher card (local only). 设备卡片显示预览图（仅保存在本机）。
- **Sign in once, controllable everywhere**: viewer sign-in starts the local host service. 控制端登录后本机自动上线、可被远控。
- **Responsive control center** and **clean recovery after dropped frames** (no smeared blocks); measured **RTT** in the network panel.
  控制中心不再卡顿；丢帧后等待关键帧恢复，不再花屏；网络面板显示实测延迟。
- **No crash** when closing the file-transfer window on Wayland. Wayland 下关闭文件传输窗口不再崩溃。
- **Launcher refresh**: system icons, calmer palette, Account card with Sign out in Settings. 启动器新图标与配色，设置中新增账号卡片与退出登录。
- **GNOME multi-monitor**: every monitor appears as a screen in the viewer; consent once per monitor, then switching never asks again.
  GNOME 多显示器：每块显示器都可在控制端切换；每块显示器只需授权一次，之后切换不再询问。
- **Precise touch on GNOME**: pointer motion and clicks go through the portal session of the shown monitor.
  GNOME 下触控精确：指针与点击经由当前显示器的门户会话。
- **Screen sharing stops when you leave**; the next connection resumes silently with the saved consent.
  断开后立即停止屏幕共享；再次连接时使用已保存的授权静默恢复。
- Device registration is serialized across processes (one sign-in cannot register two devices). 设备注册跨进程串行化。
- niri: monitor switching, rotated outputs and mobile text from upstream (#71). 合入上游 niri 支持。

Install: `uu-remote-linux_0.3.0_<amd64|arm64>.deb` or `uu-remote-linux-v0.3.0-<x86_64|aarch64>-linux.tar.gz` (`./install.sh`).
